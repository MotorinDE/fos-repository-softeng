# Логика формирования теоретического билета

- Для каждого билета случайным образом выбираются 5 проверяемых модулей
- В рамках каждого модуля случайным образом выбирается один вопрос
- Оценка ответа на вопрос формируется из корректности и полноты этого ответа
  - Ответ не корректен – 0 баллов
  - Ответ корректен, но не полон – до 1 балла (может варьироваться в зависимости от критичности не полноты ответа)
  - Ответ корректен и полон – до 2 баллов (может варьироваться в зависимости от меры полноты ответа)
- Мера корректности используется для определения знания материала студентом
- Мера полноты используется для определения понимания материала студентом
