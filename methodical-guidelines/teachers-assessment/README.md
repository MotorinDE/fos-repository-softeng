# Методические указания преподавателям по оцениванию

В таблице собраны все методические указания для преподавателей по оцениванию конкретных видов работ: устных докладов, лабораторных занятий по каждому модулю (со 2-го по 8-й), групповой игры, курсового проекта и зачёта. Для каждой работы указан отдельный файл с рубриками, критериями, шкалами баллов и рекомендациями по выставлению оценки и обратной связи. Чтобы получить готовый инструмент проверки, найдите в таблице строку, соответствующую нужному модулю и форме контроля (например, M2-databases-lab-rubric для лабораторной по SQL или exam.md для зачёта), и перейдите по ссылке — там вы найдёте все необходимые оценочные материалы.
