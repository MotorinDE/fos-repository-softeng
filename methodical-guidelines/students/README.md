# Методические указания обучающимся

В таблице перечислены все методические указания для студентов, сгруппированные по модулям и формам работ: устные доклады, лабораторные занятия, групповая игра и курсовой проект. Чтобы получить подробные инструкции по выполнению конкретного задания, найдите в таблице строку с нужным модулем и типом работы (например, «M2‑databases‑lab» для лабораторной по базам данных или «project‑methodical‑guidelines‑students» для курсового проекта) и перейдите по указанной ссылке — там содержатся пошаговые рекомендации, требования к оформлению и критерии сдачи. Все файлы доступны в этой же папке.
