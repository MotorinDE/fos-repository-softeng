# Методические указания

В таблице ниже представлены три раздела методических указаний, каждый из которых адресован своей аудитории и решает конкретную задачу: для обучающихся — инструкции по выполнению, сдаче и защите контрольно-измерительных материалов; для преподавателей по оцениванию — правила выставления баллов, рубрики, порядок обратной связи и апелляций; для преподавателей по ресурсам — рекомендации по подбору и использованию учебных материалов при разработке заданий. Пользуйтесь разделом, соответствующим вашей роли: студенты переходят в students, преподаватели — в нужный подраздел teachers-assessment или teachers-resources в зависимости от текущей задачи (проверка работ или подготовка КИМ).

| Раздел | Для кого | Содержание |
| ------ | -------- | ---------- |
| [students](students/README.md) | обучающиеся | выполнение, сдача и защита КИМ |
| [teachers-assessment](teachers-assessment/README.md) | преподаватели | оценивание, рубрики, обратная связь, апелляции |
| [teachers-resources](teachers-resources/README.md) | преподаватели | подбор и применение ресурсов при разработке КИМ |
