# Методические указания преподавателям по использованию ресурсов

В таблице приведены методические рекомендации для преподавателей по подбору и применению учебных и практических ресурсов при подготовке и проведении различных видов занятий: устных докладов, модулей 3, 4 и курсового проекта. Каждая строка указывает на конкретный файл с рекомендациями — например, для модуля 3 по Git или для курсового проекта. Чтобы получить готовые советы по источникам, инструментам и материалам, которые помогут организовать работу студентов, найдите нужную строку по названию модуля или формы контроля и перейдите по ссылке — там вы найдёте перечень ресурсов и указания по их эффективному использованию в учебном процессе.
